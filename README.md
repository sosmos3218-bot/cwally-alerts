## Dup-guard / state 저장

- `scripts/ntfy_util.py` dup-guard: 같은 제목의 `cwally-port` 재발송을 슬롯 since(`DUP_GUARD_SINCE`, 슬롯 시작 10분 전) 이후로 막습니다. `설치 확인`/`테스트` 제목은 예외. `NTFY_DUP_GUARD=0` 으로 끌 수 있습니다.
- Persist 실패 시 `scripts/persist_state.sh` 가 최대 5번 재시도하고, 끝내 실패하면 state/ artifact(7일)와 cwally-ops 안내를 남깁니다.
- 공시 알림 8종은 `dedup_key`(KIND 접수번호)로 같은 날 다른 제목의 재발송도 막습니다.
- `[PROTEC]` 주간 점검은 `state/protec.json` 의 `weekly_sent_week`(ISO `%G-W%V`) 로 주당 1번만 보냅니다.

문턱 (`configs/aptscn.json` `rules`, 단위는 주간 변동률 %):

- 상승 지속: 서울 매매 4주 평균 >= 0.15, 그리고 이번 주 경기 매매 > 0, 그리고 이번 주 서울 전세 > 0, 그리고 (은행 가계대출 월 증감 > 0 또는 금리 인하). 금리 인하는 이번 금통위 결정이 인하이거나, 신규 주담대 금리가 3개월 전보다 0.10%p 이상 하락. 시장 전망 기사는 보지 않는다.
- 본격 하락: 서울 매매와 경기 매매가 둘 다 마이너스인 주가 3주 연속, 또는 서울 전세 <= 0 이면서 (이번 결정이 인상 또는 가계대출 증감 <= 0).
- 둘 다 아니면 완만한 둔화. 하락을 먼저 본다.
- 강남3구는 서초, 강남, 송파 매매 변동의 평균. 거래량과 함께 본문 참고만 하고 분기에는 쓰지 않는다.
